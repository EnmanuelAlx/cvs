# 📄 CV Repository

A version-controlled repository for my curriculum vitae written in LaTeX.

## 📂 Structure

This repository maintains my professional CV in multiple languages across separate branches:

- **`en`** branch → English version
- **`es`** branch → Spanish version

## 🚀 Usage

To access a specific version:

```bash
# English CV
git checkout en

# Spanish CV
git checkout es
```
